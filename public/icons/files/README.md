# File icons

Full-colour icons from the Adwaita icon theme, used in the portfolio's Files app (Nautilus-style grid).

| File | Used for |
|---|---|
| `folder.svg` | Folders |
| `text-x-generic.svg` | Text and Markdown files |
| `x-office-document.svg` | Documents (the CV) |
